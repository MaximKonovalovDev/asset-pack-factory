Date: 2026-09-07

## FiveM / RedM via Tebex
- Prices: small scripts $10-30. HUDs $25. Big packs $109-120. Shops: looks $3-8, queue $5/10/20, top $50 anchor.
- Fee: 15% FiveM (normal Tebex 5%). PayPal via Tebex 2.49% + $0.40. You keep ~80-83%. Cash out $0.50 PayPal, 1.50-12 bank, +2% if change cash type.
- Tech: prop .ydr, car .yft, clothes .ydd, pics .ytd DDS, list .ytyp, place .ymap. Max 1 GB. Need lua54=yes. Use LODs + small pics with mipmaps (mipmaps = small far copies).
- AI: yes if you own it. No ripped work. AI code common. Must own rights.
- Halloween: horror maps, masks, clothes sell. Max 4 sales per year. Use short-time items.

## Horizon Worlds
- No fixed price. Cash is $50M fund in 2025. Pay for time, return visits, buys. Top contest $100k. 4 makers passed $1M. ~100 makers made 6 figs in 2025.

- Tech: Desktop Editor. Code TypeScript (web code). Build for phone first. Phone users 4x in 2025. Phone-only worlds 0 to 2,000+. Keep poly low.
- AI: yes. Meta pushes it. Prompt for maps, sound, code, shapes, skins.
- Autumn: spooky worlds + phone worlds. Return visits pay.
